# Resource Steward — دليل الاستخدام

**اللغات:** [English](README.md) · العربية · [Français](README.fr.md) · [Español](README.es.md)

Resource Steward أداة Python خفيفة لمراقبة ضغط الموارد في جلسات Linux الشبيهة بـ Arena، وفحص الظروف قبل المهام المكلفة، ومراقبة الأوامر التي تشغّلها، وتنظيم مراجعة الملفات الكبيرة.

> **النطاق والسلامة:** المشروع مستقل وغير رسمي، وليس ميزة مدمجة في Arena أو Google Drive. لا ترفع الأداة الملفات ولا تحذفها تلقائيًا. راجع الأوامر والصلاحيات قبل تشغيلها.

## الوظائف الرئيسية

- قراءة معلومات الذاكرة المتاحة عبر cgroup v2، والذاكرة المتاحة على النظام، ومساحة القرص الحرة.
- تقدير عدد الملفات وأحجامها التي قد تدخل في لقطة الجلسة.
- إجراء فحص أولي للموارد والتنبيه عند الضغط أو التعافي.
- مراقبة عملية فرعية وإيقاف مجموعة عملياتها عند بلوغ الحدود المضبوطة أو تعذّر القياس.
- حفظ قائمة محلية باستخدام SQLite لمراجعة الملفات الكبيرة.
- التحقق من حجم وبصمة MD5 لملف موجود مسبقًا في Google Drive عند توفير رمز قراءة.
- عرض مثال لنقاط الحفظ والاستئناف، بشرط أن يدعم التطبيق حفظ التقدم واستعادته.

## المتطلبات

- Linux مع `/proc` وcgroup v2.
- Python 3.10 أو أحدث.
- صدفة متوافقة مع POSIX وGit.
- لا تحتاج الوظائف الأساسية إلى حزم Python خارجية.

المشروع موجّه لبيئات Linux الشبيهة بـ Arena، وليس موثقًا كأداة عامة لنظام Android/Termux أو macOS أو Windows.

## البدء

```bash
git clone https://github.com/supermorkat/Resource-Steward.git
cd Resource-Steward
python3 --version
python3 -m unittest discover -s resource-steward/tests -v
```

راجع تعليمات المستودع ومساعدة سطر الأوامر لمعرفة الصيغة الدقيقة للأوامر في النسخة التي تستخدمها، ولا تفترض أن مراقبة الموارد تضمن إمكانية إيقاف المهمة أو استئنافها بأمان.

## ملاحظات مهمة

- القياسات تعتمد على المعلومات التي تتيحها البيئة، وهي تقديرات وليست ضمانات.
- قد يؤدي الإشراف إلى إنهاء الأمر عند بلوغ الحدود أو فقدان القياسات؛ استخدمه مع أوامر يمكنك تقبّل إيقافها.
- نقاط الحفظ مسؤولية التطبيق نفسه؛ يجب أن يحفظ التطبيق تقدمه وأن يعرف كيف يستعيده.
- التحقق من Google Drive يفحص بيانات ملف موجود ولا ينفّذ الرفع.
- لا تضع رموز الوصول في الشيفرة أو المستودع، واتبع آلية متغيرات البيئة الموثقة في المشروع.
- راجع عناصر قائمة الملفات الكبيرة قبل اتخاذ أي إجراء بشأنها.

## الاختبارات والتطوير

من جذر المستودع شغّل:

```bash

```

حدّث الاختبارات عند تعديل حدود الموارد أو مراقبة العمليات أو التخزين أو التحقق من Drive.
